# Folio

React-клиент платформы для цифровых авторов: иллюстрации, анимация, интерактивные 3D-модели, настраиваемое портфолио и заявки от заказчиков. Сервер находится в отдельном [репозитории folio-backend](https://github.com/skeiigi/folio-backend).

## Локальный запуск

Требуется Node.js 22. Сначала запустите API по его README, включая миграцию и демо-данные. Затем в этом репозитории:

```bash
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173`. Vite пересылает `/api/v1` на локальный сервер `:4100`, поэтому для разработки `.env` не требуется. Для собственного адреса API скопируйте `.env.example` в `.env.local` и измените `VITE_API_URL`. Эта переменная попадает в публичный браузерный код: ключи доступа и `DATABASE_URL` здесь недопустимы.

Демо-входы доступны только в режиме разработки: заказчик `anton@folio.test`, авторы `mira@folio.test`, `lea@folio.test`, `nikita@folio.test`, администратор `admin@folio.test`. Пароль после стандартного сидирования сервера — `FolioDemo2026!`. В production кнопки быстрого демо-входа не отображаются.

## Экраны

| Экран | Что работает |
| --- | --- |
| Главная / каталог | Поиск, типы работ, стили, пагинация, карточки авторов |
| Работа | Галерея, технические сведения, вращение реальной GLB-модели через `model-viewer` |
| Авторы / профиль | Портфолио, специализация, услуги, цены, сроки, оформление автора |
| Вход / регистрация | Отдельные роли, защищённые маршруты, возврат на исходную страницу |
| Мастерская | Свои работы, профиль, настройки оформления, услуги, загрузка файлов и публикация |
| Бриф / заявки | Форма, бюджет, срок, приватные референсы, статусная доска и история |
| Аккаунт / администрация | Имя, пароль, завершение доступа, управление пользователями и публикациями |

Автор управляет темой, акцентом, типографикой, порядком и видимостью секций, числом колонок. Настройки сохраняются в профиле и применяются при публичном просмотре. Для безопасности произвольный код внутри профиля не запускается. Позже его можно исследовать как отдельную изолированную функцию.

В данных есть настоящие двоичные GLB-файлы, а не только изображения моделей. Компонент просмотра подгружается отдельно при открытии страницы 3D-работы; поэтому сборщик выводит предупреждение о размере его отдельного блока, хотя основной каталог остаётся значительно меньше.

## Сборка и размещение

```bash
npm run check
npm run build
npm run preview
```

`dist/` — готовый статический сайт. В репозитории есть `vercel.json` и `netlify.toml` для SPA-навигации, поэтому фронтенд можно разместить независимо от Node API. На Vercel установите `VITE_API_URL=https://<ваш-api>/api/v1` **до сборки**. На сервере разрешите точный origin фронтенда через `CORS_ORIGINS`. API и PostgreSQL публикуются отдельно; домены и секреты вводятся владельцем сервисов после выбора хостинга. Конфигурация уже подготовлена, опубликованного URL пока нет.

Визуальный шрифт Manrope включён локально с лицензией в `public/licenses`. Примеры обложек генерируются сервером; чужие изображения и шрифты при открытии сайта не запрашиваются.

Архитектура и связь экранов с учебными работами описаны в [docs/COURSEWORK.md](docs/COURSEWORK.md). Проверенные сценарии и скриншоты — в `docs/screenshots`.
